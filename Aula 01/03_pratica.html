Passo 1 — Criar classe de teste
📋 Instrução: Crie a estrutura básica de uma classe CalculadoraTest com @Test para verificar que somar(2, 3) retorna 5.
💡 Dica: Use assertEquals(esperado, resultado).
class CalculadoraTest { @Test void somaDoisPositivos() { Calculadora c = new Calculadora(); assertEquals(5, c.somar(2, 3)); } }
Passo 2 — Testar subtração
📋 Instrução: Escreva um teste para verificar que subtrair(10, 3) retorna 7 com uma mensagem de falha descritiva.
💡 Dica: assertEquals(esperado, real, "mensagem").
@Test void subtraiCorretamente() { Calculadora c = new Calculadora(); assertEquals(7, c.subtrair(10, 3), "10 - 3 deve ser 7"); }
Passo 3 — @BeforeEach
📋 Instrução: Adicione @BeforeEach que instancia a Calculadora e reutilize em dois testes diferentes.
💡 Dica: Declare o campo como atributo da classe.
Calculadora calc; @BeforeEach void setUp() { calc = new Calculadora(); } @Test void soma() { assertEquals(5, calc.somar(2,3)); } @Test void subtrai() { assertEquals(7, calc.subtrair(10,3)); }
Passo 4 — assertNotNull
📋 Instrução: Escreva um teste que verifica que o construtor de Calculadora não retorna null e que o histórico inicial não é null.
💡 Dica: Use assertNotNull(objeto).
@Test void construtorNaoRetornaNulo() { Calculadora c = new Calculadora(); assertNotNull(c); assertNotNull(c.getHistorico()); }
Passo 5 — Nomear testes corretamente
📋 Instrução: Renomeie estes testes com nomes descritivos: teste1(), teste2(), testeCalculo().
💡 Dica: Use o padrão: deveRetornarX_QuandoY().
// teste1() → deveRetornar5_QuandoSomar2e3() // teste2() → deveLancarExcecao_QuandoDividirPorZero() // testeCalculo() → deveCalcularIMC_QuandoPesoEAlturaValidos()
