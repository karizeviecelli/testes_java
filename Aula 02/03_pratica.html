🛠 Aula 02 · Prática — Assertions Avançadas e @ParameterizedTest

00:00
Passo 1 — assertThrows com mensagem
📋 Instrução: Escreva teste que verifica que dividir(5, 0) lança ArithmeticException e que a mensagem contém "zero".
💡 Dica: assertThrows retorna a exceção — use .getMessage().contains().
@Test void deveLancar_QuandoDividirPorZero() { ArithmeticException ex = assertThrows( ArithmeticException.class, () -> calc.dividir(5, 0) ); assertTrue(ex.getMessage().contains("zero")); }
Passo 2 — assertAll em objeto
📋 Instrução: Crie um Produto("Caneta", 2.50) e use assertAll para verificar nome, preço e que descricao não é null.
💡 Dica: assertAll("grupo", () -> ..., () -> ...).
@Test void verificaProduto() { Produto p = new Produto("Caneta", 2.50); assertAll("produto", () -> assertEquals("Caneta", p.getNome()), () -> assertEquals(2.50, p.getPreco()), () -> assertNotNull(p.getDescricao()) ); }
Passo 3 — @ValueSource com Strings
📋 Instrução: Escreva @ParameterizedTest com @ValueSource(strings) para verificar que "Java", "Python" e "Go" são linguagens válidas.
💡 Dica: Use assertTrue(Linguagem.ehValida(s)).
@ParameterizedTest @ValueSource(strings = {"Java","Python","Go"}) void deveSerLinguagemValida(String lang) { assertTrue(Linguagem.ehValida(lang)); }
Passo 4 — @CsvSource para cálculo de IMC
📋 Instrução: Use @CsvSource para testar calcularIMC com: (70,1.75,22.86), (90,1.80,27.78), (60,1.60,23.44).
💡 Dica: @CsvSource({"70,1.75,22.86", ...}).
@ParameterizedTest @CsvSource({"70,1.75,22.86","90,1.80,27.78","60,1.60,23.44"}) void calculaIMC(double peso, double alt, double esp) { assertEquals(esp, IMC.calcular(peso, alt), 0.01); }
Passo 5 — @DisplayName descritivo
📋 Instrução: Adicione @DisplayName a 3 testes com nomes de negócio, como "Deve calcular desconto VIP de 20%".
💡 Dica: O nome deve descrever o comportamento, não o método.
@Test @DisplayName("Deve calcular desconto VIP de 20%") void descontoVip() { ... } @Test @DisplayName("Deve rejeitar e-mail sem @ no cadastro") void emailInvalido() { ... }
