Passo 1 — Red: String Calculator
📋 Instrução: Escreva o teste Red para uma StringCalculator.add("") que deve retornar 0. A classe ainda não existe.
💡 Dica: O teste deve falhar com ClassNotFoundException primeiro.
@Test void deveRetornar0_QuandoStringVazia() { // RED: StringCalculator não existe ainda assertEquals(0, StringCalculator.add("")); }
Passo 2 — Green: String Calculator
📋 Instrução: Implemente o mínimo para o teste anterior passar: add("") retorna 0.
💡 Dica: Return 0 diretamente — não faça mais do que o teste pede.
public class StringCalculator { public static int add(String numeros) { if (numeros.isEmpty()) return 0; return 0; // mínimo para passar } }
Passo 3 — Segundo ciclo: um número
📋 Instrução: Escreva o Red para add("5") retornar 5, depois o Green mínimo.
💡 Dica: Só adicione lógica para o novo teste — não antecipe cenários futuros.
// Red @Test void deveRetornarNumero_QuandoUmValor() { assertEquals(5, StringCalculator.add("5")); } // Green if (!numeros.isEmpty() && !numeros.contains(",")) return Integer.parseInt(numeros);
