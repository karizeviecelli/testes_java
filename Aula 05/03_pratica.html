Passo 1 — @WebMvcTest setup
📋 Instrução: Monte a estrutura de AlunoControllerTest com @WebMvcTest, MockMvc autowired e @MockBean para o service.
💡 Dica: @WebMvcTest(AlunoController.class) na classe.
@WebMvcTest(AlunoController.class) class AlunoControllerTest { @Autowired MockMvc mockMvc; @MockBean AlunoService service; }
Passo 2 — GET retorna 200
📋 Instrução: Escreva um teste MockMvc que verifica GET /alunos retorna status 200.
💡 Dica: mockMvc.perform(get("/alunos")).andExpect(status().isOk()).
@Test void deveRetornar200() throws Exception { mockMvc.perform(get("/alunos")) .andExpect(status().isOk()); }
Passo 3 — jsonPath no corpo
📋 Instrução: Verifique que GET /alunos/1 retorna JSON com campo "nome" igual a "Ana".
💡 Dica: andExpect(jsonPath("$.nome").value("Ana")).
when(service.buscar(1L)).thenReturn(new Aluno("Ana")); mockMvc.perform(get("/alunos/1")) .andExpect(status().isOk()) .andExpect(jsonPath("$.nome").value("Ana"));
Passo 4 — POST com body
📋 Instrução: Escreva teste para POST /alunos com body JSON {"nome":"João"} que retorna 201 Created.
💡 Dica: Use .content(json) e .contentType(APPLICATION_JSON).
mockMvc.perform( post("/alunos") .contentType(MediaType.APPLICATION_JSON) .content("{\"nome\":\"João\"}") ).andExpect(status().isCreated());
Passo 5 — @DataJpaTest
📋 Instrução: Crie AlunoRepositoryTest com @DataJpaTest que salva um Aluno e verifica que findByNome("Ana") retorna 1 resultado.
💡 Dica: @DataJpaTest usa H2 in-memory automaticamente.
@DataJpaTest class AlunoRepositoryTest { @Autowired AlunoRepository repo; @Test void deveBuscarPorNome() { repo.save(new Aluno("Ana")); assertEquals(1, repo.findByNome("Ana").size()); } }
