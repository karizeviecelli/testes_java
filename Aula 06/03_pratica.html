🛠 Aula 06 · Prática — Cobertura de Código com JaCoCo

00:00
Passo 1 — Adicionar JaCoCo ao pom.xml
📋 Instrução: Escreva o plugin JaCoCo completo no pom.xml com prepare-agent e report configurados.
💡 Dica: Use artifactId jacoco-maven-plugin, versão 0.8.11.
<plugin> <groupId>org.jacoco</groupId> <artifactId>jacoco-maven-plugin</artifactId> <version>0.8.11</version> <executions> <execution> <goals> <goal>prepare-agent</goal> <goal>report</goal> </goals> </execution> </executions> </plugin>
Passo 2 — Threshold de line coverage
📋 Instrução: Adicione execution de check para falhar o build se line coverage cair abaixo de 80%.
💡 Dica: counter LINE, minimum 0.80.
<execution> <id>check</id> <goals><goal>check</goal></goals> <configuration> <rules><rule><limits> <limit> <counter>LINE</counter> <minimum>0.80</minimum> </limit> </limits></rule></rules> </configuration> </execution>
Passo 3 — Excluir classes
📋 Instrução: Configure o JaCoCo para excluir todos os arquivos em dto/, config/ e a classe Application.class.
💡 Dica: Use excludes com padrões glob.
<excludes> <exclude>**/dto/**</exclude> <exclude>**/config/**</exclude> <exclude>**/*Application.class</exclude> </excludes>
Passo 4 — Gerar relatório e verificar
📋 Instrução: Escreva o comando Maven para gerar o relatório JaCoCo e onde encontrá-lo após a execução.
💡 Dica: mvn verify gera tudo de uma vez.
# Gerar relatório mvn verify # Relatório HTML em: target/site/jacoco/index.html # Dados brutos em: target/jacoco.exec
Passo 5 — JaCoCo Gradle
📋 Instrução: Configure o plugin JaCoCo no Gradle com relatório HTML habilitado e threshold de 80%.
💡 Dica: Use jacocoTestReport e jacocoTestCoverageVerification.
plugins { id 'jacoco' } jacocoTestReport { reports { html.required = true } } jacocoTestCoverageVerification { violationRules { rule { limit { minimum = 0.80 } } } }
